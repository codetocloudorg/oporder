# oporder (placeholder)

This package reserves the `oporder` name on npm. **It does not install a working tool.**

OpOrder is a vendor-neutral assessment CLI for cloud migration and application modernization
— reads your code and your live infrastructure, tells you honestly what's actually there, and
hands you a plan without an opinion about which cloud you should end up on.

It's a Go binary distributed via [GitHub
Releases](https://github.com/codetocloudorg/oporder/releases), not primarily an npm package —
this placeholder exists so `npm install -g oporder` resolves to the real project the moment a
binary exists, instead of the name being unavailable or squatted by something unrelated.

- **Repository**: https://github.com/codetocloudorg/oporder
- **Specification**: https://github.com/codetocloudorg/oporder/blob/main/SPEC.md
- **Site**: https://oporder.dev

No binary yet. Follow the repository for progress.
